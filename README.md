# Lab 6 - Sampling and Bias

## Goal
To understand why choosing the right sample matters when working with data.

## What I did
I used the Titanic dataset to compare regular and stratified train-test splits and then i looked at data leakage and why information from the test set should not be used during training. Finally, i tested a function for splitting data and looked at how biased samples can give misleading results.

## What I learned
I learned that having more data doesn't always mean getting better result and that keeping the groups balanced and avoiding data leakage helps make the results more reliable.
